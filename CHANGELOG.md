# Changelog

## 1.0.0

- First public release as a standalone stdio MCP server.
- 24 structured tools across project management, Word (Writer), Excel (Calc), PowerPoint (Impress), and export.
- Persistent atomic JSON document models with 30-step undo/redo.
- WPS COM rendering to DOCX, XLSX, PPTX, and PDF on Windows x64.
- Dedicated COM instance where supported, leaving the user's existing WPS windows untouched.
- Overridable workspace via the `WPS_CLI_WORKSPACE` environment variable.
